## About

[FinHorizons Foundation](https://finhorizons.org) is an open research community advancing responsible AI in finance. This repository collects the public materials from our activities: speaker slides, links to recordings, reading lists and event resources.

## Layout

| Folder | Contents |
|--------|----------|
| [`seminars/`](./seminars) | FinHorizons Seminar series: online talks by researchers and practitioners, every Saturday |
| [`reading-group/`](./reading-group) | Reading group sessions: papers discussed, presenter slides and notes |
| [`community-events/`](./community-events) | Workshops, tutorials, panels, invited talks and other community events |

Each event has its own folder named `YYYY-MM-DD_<speaker or event>` containing the slides (PDF) and a README with the abstract, speaker bio, recording link and related papers.
